# Source provenance and reproducibility scope

This release packages the supplied research implementation accompanying `Sim2Act_AIC_Manuscript1031.docx`. It is a source and paper-results release; remote orchestration (including `step3b/runner.py`), raw datasets, HDF5 evidence caches, trained checkpoint tensors, SSH configuration and third-party repository copies are excluded.

## Source lineage

Paths below identify local source material used during assembly; they are not runtime requirements.

- `remote_setup_gpu/step4b_source/src/sim2act_baselines/`: baseline package, data/cache APIs, causal active methods, fusion, geometry extraction and metrics.
- `remote_setup_gpu/step5a_public_source/package/sim2act/`: model, causal feature schema/extraction, exact Oracle gains, loss, dataset writer/loader, trainer, evaluator and closed-loop selector.
- `remote_setup_gpu/step5b_public_source/package/sim2act/`: final `step5b_dataset.py` and `step5b_models.py`.
- `step5c_geometry_recovery_v1/step5c_geometry_small_cluster_v1.py`: the final versioned geometry fallback, included as `sim2act_baselines.extraction.step5c_geometry_small_cluster_v1`.
- `_numeric_audit_handoff/05_METHOD_SOURCE_SNAPSHOT/`: final locked compact snapshot. Its 19 Python source files were byte-identical to their corresponding staged files before packaging. All scientific computations are preserved; the import relocation described below affects one of these 19 files.

No replacement model, synthetic demonstration implementation or fabricated training result was introduced.

## Release packaging changes

Four files differ from the supplied source:

1. `active/reveal_manager.py`: import h5py within the HDF5-reading methods, allowing in-memory `RevealedViewEvidence` and NumPy-only selectors to load without h5py. Evidence gating and numerical operations are unchanged.
2. `evaluation/__init__.py`: resolve the original public exports lazily, avoiding geometry dependencies for standalone semantic metrics.
3. `sim2act/__init__.py`: resolve the original model and selector exports lazily, allowing the feature schema to load without PyTorch.
4. `sim2act/access_guard.py`: default the file-access audit log to `sim2act_access.jsonl`, or the `SIM2ACT_ACCESS_LOG` environment variable, rather than an unavailable remote machine directory. The sealed-data rejection rules remain unchanged.

The installation metadata and this documentation are new release files. The eight test modules are copied unchanged from the supplied Step 4B tests.

## Installation and supported scope

```bash
pip install -e .
pip install -e ".[learning,test]"
pytest
```

The base install supports in-memory causal state/selection, semantic metric primitives and schema inspection using NumPy. The `learning` extra supplies PyTorch and h5py for model, training and evidence-cache APIs. The `science` extra supplies declared geometry/scientific Python dependencies. It does not install CrackStructures, ENSTRECT, OmniCrack30k or PyTorch3D; obtain these separately with compatible upstream versions. CUDA/PyTorch3D builds and trained segmentation weights require their upstream setup instructions.

The recorded experiment core used torch 2.3.1, torchvision 0.18.1, torchaudio 2.3.1, PyTorch3D 0.7.7, NumPy 1.26.4 and Open3D 0.19.0. This is provenance, not a complete lockfile. The source package keeps NumPy below version 2 for compatibility with the recorded upstream stack. Optional-extra bounds declare API dependencies and do not assert a newly validated GPU environment.

Research APIs include `sim2act_baselines.sim2act.model.Sim2ActViewRanker`, `sim2act_baselines.sim2act.evaluator.evaluate_ranking`, and `sim2act_baselines.sim2act.closed_loop_selector.Sim2ActClosedLoopSelector`. The retained `trainer.train_smoke` is the original bootstrap training helper, not the final Step 5B experiment orchestrator. Inspect API signatures before use; the caller supplies evidence, causal states and training data.

The original full experiment entry scripts read frozen report/configuration files and use absolute remote paths at import time. They are intentionally excluded. Some lower-level research APIs retain original evidence-metadata assumptions and dataset layout conventions, including the original `state_sampler.STEP4B_TRIALS` evidence path; callers must supply their own research inputs. The remote `step3b/runner.py` orchestrator is excluded. This release does not provide a portable end-to-end CLI, recreate evidence caches, or reproduce the complete final training/evaluation run without those external artifacts. Model weights are not included.

## Verification performed for this release

- Compiled all 77 shipped Python source files and eight test files in memory without generating source-tree bytecode.
- Executed ten existing assertion tests directly using the bundled Python runtime and its NumPy 2.3.5. These cover deterministic tie-breaking, fixed-seed random selection, pool exhaustion without duplicates, geometry-only candidate fields, absence of ground truth in deployable selector code, Oracle equivalence to independent brute force on fixed and random pools, negative-control metrics, and separate raw/best-so-far curves.
- Parsed the TOML metadata successfully.
- pytest was unavailable in that runtime, so the two pytest-dependent budget assertions were not executed. GPU training, model forward passes, cache I/O and geometry extraction were not executed because their dependencies/data were unavailable. No scientific experiment was rerun.
